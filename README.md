# 🚨 IncidentForge MCP

Structured security incident response, communications and blameless postmortem workflow.

IncidentForge separates confirmed facts, hypotheses and unknowns; builds timelines, assesses impact, classifies severity, plans containment and recovery, drafts reviewed communications and creates corrective actions.

## Tools

- `incident.architect`
- `timeline.build`
- `impact.assess`
- `severity.classify`
- `response.plan`
- `communications.draft`
- `postmortem.build`
- `incident.report_live`
